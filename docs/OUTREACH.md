# Outreach Workflow

## Rule

Draft first, send second. A human reviews both evidence and message.

## Draft structure

1. Business-specific observation.
2. Concrete website/customer-journey issue.
3. Short proposal.
4. Low-friction next step.

If a source lacks a website field, say that no independent website was found in the reviewed sources. Do not state it as an absolute fact until verified.

Initial deterministic templates: EN / TR / DE.
