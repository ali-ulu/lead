# Kullanım

## Windows
`START_WINDOWS.bat` dosyasına çift tıkla.

## macOS
`START_MAC.command` dosyasına çift tıkla.

## Linux
`./start.sh`

Tarayıcı otomatik olarak `http://127.0.0.1:8787` adresini açar.

Uygulamada ülke (isteğe bağlı), şehir/bölge, sektör ve yarıçap seçip **Find live leads** düğmesine bas. Sonuçlarda websitesiz işletmeleri filtreleyebilir, sitesi olanları **Audit website** ile denetleyebilir, mesaj taslağı oluşturabilir, pipeline durumunu değiştirebilir ve CSV dışa aktarabilirsin.

API anahtarı gerekmez. n8n, Apify veya ücretli CRM gerekmez. Veriler yerel SQLite veritabanında tutulur.
